GitHub-hosted runners, as they actually are

Every runner image below is captured once a day with Nyrvo and committed to a public repository. What each mark in the table means is spelled out beneath it: the three kinds of "no version here" are different facts about a machine, and a workflow that treats them alike is the reason this page exists.

A commit exists only when something actually changed, so git log on that repository is the history. Changed below is the date each image last moved.
